# Metergraph community defaults

This repository supplies the default issue forms, pull request template, and
contribution guidelines for repositories owned by the `metergraph` GitHub
organization. A repository's own template takes precedence. Repositories in
other organizations need their own copies.

The public publishing rules are in [AGENTS.md](AGENTS.md). Agents working in
another repository need that repository's own `AGENTS.md`; GitHub community
defaults do not place agent instructions in checkouts.
